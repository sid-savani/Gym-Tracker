# Product Roadmap

This document outlines the high-level phased roadmap for the gym workout tracker application. 

> [!NOTE]
> This roadmap is intentionally lightweight, flexible, and subject to evolution based on user feedback and development learnings.

---

### Phase 0 — Foundation
- Project setup, repository initialization, and engineering guidelines
- Centralized design system and theme tokens (Light & Dark mode)
- Core architectural foundations and navigation setup

### Phase 1 — Core Workout Logging
- Fast, clutter-free active workout session logging
- Exercise selection and custom exercise creation
- Set logging (weight, reps, RPE, rest timer)
- Local data persistence

### Phase 2 — Workout History + Progressive Overload
- Workout history log and detailed session summaries
- Previous performance indicators and progressive overload suggestions
- Exercise personal records (PRs) and estimated 1RM calculations

### Phase 3 — Insights + Goals + Habit Tracking
- Workout frequency, volume, and duration analytics
- Visual charts and progress graphs
- Consistency, streaks, and fitness goal tracking

### Phase 4 — Nutrition / Macros
- Daily calorie and macronutrient logging (protein, carbs, fats)
- Macro goal targets and daily tracking summaries

### Phase 5 — Accounts + Cloud Sync
- User account authentication
- Cloud database integration and multi-device sync
- Data backup and export/import options

### Phase 6 — Social / Friends
- Friend connections and activity feeds
- Shared workouts and achievement sharing

### Phase 7 — AI Coaching
- Smart workout recommendations and plate math assistance
- AI-driven progressive overload adjustments and recovery suggestions

### Phase 8 — Gym / B2B Capabilities
- Personal trainer client management
- Gym facility integrations and shared programming
